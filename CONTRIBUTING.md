# Contributing

This project welcomes contributions from people who support permanent standard time, permanent DST, or the existing system. Our disclosed policy preference does not mean factual disagreements are unwelcome.

## Useful contributions

- Corrections to the legislation or sources.
- Original technical incident records and vendor documentation.
- Peer-reviewed research and evidence that challenges a claim.
- Small, reproducible programming examples with pinned time-zone rules.
- Clear alternative interpretations and proposed implementation safeguards.

## Evidence standard

Clearly distinguish **documented fact**, **engineering inference**, **policy preference**, and **unverified hypothesis**. Link primary sources near the relevant assertion. Supply publication dates, precise sections, and limitations whenever possible. Do not present cost forecasts as realized losses or single examples as universal predictions.

## Lightweight workflow

1. Open a GitHub issue for a substantive question, correction, or proposed addition.
2. Submit a focused pull request for a specific change.
3. Explain the claim, source, and any counterevidence.
4. Keep Markdown human-readable; prefer ordinary Markdown links to HTML.
5. Respond to factual review and correct mistakes transparently.

No build tool or formatter is required for documentation contributions.

## Technical examples

Document the runtime and time-zone database versions, inputs, intended local-time semantics, expected outputs, and what is being illustrated. Minimize dependencies. Do not include credentials, real personal data, or production system access. Label hypothetical rules as synthetic.

## Community standards

Critique ideas rather than people. Do not harass contributors, publish private correspondence without permission, or claim endorsement from IANA, the IETF, medical organizations, or an employer without authorization.

The maintainers retain the project's transparent advocacy position while welcoming evidence-based corrections and discussion of alternatives.
